# NoronhaMapExporter showcase assets

Generated Tourist, Clean, and SatMap tiles for the Fernando de Noronha
interactive showcase.

The exporter source and documentation live in
[AdriianCOE/NoronhaMapExporter](https://github.com/AdriianCOE/NoronhaMapExporter).
This repository is intentionally separate so a normal exporter clone does not
download the generated map pyramid.
